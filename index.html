User Accounts

Accounts are stored locally in this browser. Passwords are saved only as SHA-256 hashes — never in plain text. Roles decide what each person may change: Admin (everything, incl. users & settings), Receptionist (patients, appointments, billing, lab orders), Pharmacist (medicines & dispensing), Lab Technician (lab tests & results).

About MediCore

MediCore v1.3 — a single-file clinic & hospital management system with user login and role-based access control. It ships with no default accounts — the first Admin account is created on first run, and demo accounts exist only if you explicitly load the demo. No server, no internet and no installation required: open this file in any modern browser. Figures are estimates for management use; always verify critical records.
