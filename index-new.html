User Accounts

Accounts are stored locally in this browser. Passwords are saved only as salted, iterated hashes (50,000-round salted SHA-256, unique salt per account) — never in plain text. Sessions expire after 30 minutes of inactivity. Roles decide what each person may change: Admin (everything, incl. users & settings), Receptionist (patients, appointments, billing, lab orders), Pharmacist (medicines & dispensing), Lab Technician (lab tests & results).

Data Backup

Download a complete backup of all clinic data — patients, doctors, appointments, invoices, pharmacy stock, purchases, expenses, lab records and user accounts (passwords stay hashed) — as a single JSON file, and keep it somewhere safe. Restoring a backup replaces all current data with the backup's data; before anything is replaced, the current data is kept aside in this browser as a safety copy.

About MediCore

MediCore v1.4 — a single-file clinic & hospital management system with user login and role-based access control. The pharmacy runs on batch-based stock: every purchase is recorded with its batch number, buy price, expiry and supplier, stock updates itself from purchases and sales (it is never edited by hand), and profit is reported after deducting expenses. It ships with no default accounts — the first Admin account is created on first run, and demo accounts exist only if you explicitly load the demo. No server, no internet and no installation required: open this file in any modern browser. Figures are estimates for management use; always verify critical records.
